   turret Sprite2D nodes ONE shared ShaderMaterial using

   variable. Enemies get no material. Make the smallest possible change to

   gameplay logic. If you need a hook in tank.gd or player.gd, explain why in
   your report before adding it. Use uniform names exactly as declared in the
