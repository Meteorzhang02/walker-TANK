Task: write in-engine capture tools for the Use It human checks. Each tool
extends SceneTree, is run by the human in a real WINDOWED run (not headless):
  "<godot console exe>" --path . --resolution 1280x720 --script res://tools/<tool>.gd
loads its scene with change_scene_to_file, waits enough frames for it to be
drawn, takes its captures, prints a table, writes a CSV, and quits 0 (or 1 on
error). Captures and CSVs go to res://docs/a5/captures/ (create the folder
with DirAccess). Every capture uses exactly this function from the assignment
(adapt only the signature if a capture has no driver; then skip set_process):

func capture(driver: Node, mat: ShaderMaterial, param: StringName, value: float, path: String) -> void:
	driver.set_process(false)  # also set_physics_process(false) if the driver writes there
	mat.set_shader_parameter(param, value)
	await RenderingServer.frame_post_draw
	get_viewport().get_texture().get_image().save_png(path)
	driver.set_process(true)

Before each capture also await one extra process frame so the parameter is in
the frame that is drawn, and check after saving that the parameter still has
the value set (print it).
