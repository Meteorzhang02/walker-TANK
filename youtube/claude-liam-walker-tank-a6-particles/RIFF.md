# RIFF — the commentary's angle

The film's thread: **a particle effect is a message, and the strip, the test and the eye each see a different part of it.**

- Headless tests prove the logic (who fires, where, when, how many) and nothing drawn.
- Fixture strips show the look one still at a time, with a fixed seed. They drove A's revision (the student saw nothing to change in the game) and failed to show B's rise.
- The running game is where motion lives: the student saw B's lump, which drove R5, and later saw B rise, overruling Claude's "prediction failed".
- The code explains what neither strip nor eye could: line 447 turns each puff's heading 10–20 % per step, so a puff random-walks round the turret. That explanation is from reading the code, not from a turbulence-off strip.
- Prices: the first script measured the frame clock, and the empty control exposed it. FPS hides the cost; GPU time shows it.
